## Problem

We want to convert the code on this branch from a NextJS application (which uses some server-side rendering and data-fetching) to a client-side-only SPA developed with Vite)

We are writing this in Cursor, so recording the important files in a `.cursor/rules/important-files.mdc` file is important.

We need to remove all the Next JS libraries and configuration files and use Vite and a Vite config file instead. We want everything to still be TypeScript where possible.

## Supporting Information

### Tools

#### `pnpm`

Continue to use `pnpm` as the package manager.

## Files

#### `.cursor/rules/important-files.mdc`

A new file that lists the important files for the project, which should be included in every chat.

Use the `mdc` format, which is a markdown format with these frontmatter fields:

```md
---
globs: **/**
alwaysApply: true
---

...content goes here...
```

Make sure to add a directive at the end of the file that if new files are added, they should be added to the `important-files.mdc` file.
