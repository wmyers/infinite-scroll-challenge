# Answer First Rule

When a user asks "was there a reason for this" or similar questions about previous actions or decisions:

1. STOP any planned changes or actions
2. FIRST provide a clear explanation of the reasoning behind the previous action/decision
3. Be honest about any mistakes or oversights
4. Only AFTER providing the explanation, ask if the user would like you to proceed with any changes
5. Wait for user confirmation before making any changes

This rule ensures that we maintain transparency and give users the context they need before proceeding with any modifications.

Example:
User: "was there a reason for this?"
Assistant: [Explains the reasoning first]
Assistant: "Would you like me to proceed with any changes?"

NOT:
User: "was there a reason for this?"
Assistant: [Starts making changes immediately]
